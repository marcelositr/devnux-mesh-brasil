# Registro de decisões

Este diretório preserva decisões explícitas que afetam arquitetura, segurança, protocolo ou processo de validação. Uma entrada é um registro histórico, não uma autorização automática para implementar novas funcionalidades.

## Convenção

Cada decisão deve incluir estado, contexto, decisão, consequências e evidências. Estados sugeridos: proposta, aceita, substituída ou rejeitada. Uma proposta não deve ser descrita como decisão aprovada.
